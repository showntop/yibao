# 分享送素材——手机一键存进译宝（零 App 代码方案）

把手机上看到的文章/文字一键存进译宝素材库：不装任何新 App，用系统「分享」直达到译宝的 `/v1/save` 端点。**当前在局域网内可用**（手机与电脑同一 WiFi）；外网需等联网方案（见仓库 spec §13 注记）。

## 准备：拿两个值

1. **大脑地址**：桌面译宝 → 设置 → 手机伴生端 → 局域网开关开启（如已开启忽略）→ 记下配对二维码页显示的地址，形如 `http://192.168.31.52:19527`（以你 Mac 的内网 IP 为准；换网/IP 变了要同步改）
2. **Token**：同页面「连接 token」→ 显示 → 复制（32 位十六进制）

## iOS：快捷指令（一次配置，长期使用）

1. 打开「快捷指令」App → 右上角 **+** 新建
2. 添加动作 **「在分享表单中显示」**：接收类型勾选**文本**和**网址**（Safari 分享网页时才有 URL）
3. 添加动作 **「获取 URL 的内容」**，配置：
   - URL：`http://<大脑地址>/v1/save`
   - 展开「显示更多」：方法 **POST**、请求体 **JSON**：
     | 键 | 类型 | 值 |
     |---|---|---|
     | `text` | 快捷指令输入 | （选「快捷指令输入」变量） |
     | `title` | 文本 | 留空 |
     | `url` | 快捷指令输入 | （选「快捷指令输入」，没有就删掉这行） |
     | `mode` | 文本 | `material` |
   - 请求头：`X-Yibao-Token` = `<你的 token>`，`Content-Type` = `application/json`
4. 命名为「发给译宝」→ 完成。以后任何 App 里：分享 → 选「发给译宝」，即存入素材库

## Android：HTTP Shortcuts（开源应用）

1. Play 商店 / F-Droid 安装 [HTTP Shortcuts](https://http-shortcuts.rmy.ch/)
2. 新建 Shortcut：
   - Method `POST`，URL `http://<大脑地址>/v1/save`
   - Request Body → Custom Text（JSON）：`{"text": "{{input}}", "title": "", "url": "", "mode": "material"}`（开启 Share 接收后 `{{input}}` 即分享进来的文本；`url` 留空即可，与 iOS 表对齐——服务端对空值本就容忍）
   - Request Headers：`X-Yibao-Token: <你的 token>`
3. 应用设置 → **Share** 接收 → 启用，Shortcut 设为可被分享调用
4. 任何 App：分享 → HTTP Shortcuts → 存入

## 验证

分享一段文字后，桌面译宝打开「素材库」面板——新条目应在数秒内出现（存的是「先存后整理」：标题先占位，摘要标签后台补）。失败排查：手机和电脑是否同一 WiFi、地址 IP 是否过期、token 是否被重置过。

## 局限与安全须知

- **仅局域网**：外网分享要等联网方案恢复（个人电脑接手后启用）
- **token 明文存在快捷指令里**：快捷指令可被 iCloud 同步/导出，敏感环境请知悉；token 可在桌面设置页随时重置（重置后旧手机配置要换新值）
- 分享的正文即上云走译宝的素材整理链路（与浏览器扩展「素材桥」同一条路）
