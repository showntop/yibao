# 译宝 Roadmap 规划（R4 收口后 · 2026-08-20）

> 基于当日全仓 review（sidecar / 七插件 / 三端壳 / 37 specs + 52 plans）整理。
> 定位回顾：macOS 桌面 AI 桌宠 agent「团子」——Tauri 壳 + Python sidecar 大脑 + 插件生态 + 手机伴生端 + 浏览器素材桥。

## 一、现状盘点

### 成熟度总览

| 子系统 | 状态 | 依据 |
|---|---|---|
| sidecar 大脑 | 生产级 | 12.4k 行 src / 21.2k 行 tests，**1093 用例全绿**；mem0+fastembed 记忆、sherpa 语音、加密感知、风险闸门+审计、单实例自愈 |
| coding 插件 | 成品级·主战场 | ~11k 行（唯一 module 型面板 + 前端工程化）；R4 五阶段（module 面板运行时→studio 重写→多工位→review 栏→收口）刚完成 |
| 其余六插件 | 成品 | zimeiti（自媒体全流程）、agents（CLI 智能体调度+沙箱）、forge（需求磨刀）、toolbox、reminders、notes（全声明式标杆） |
| 桌面壳 app | 功能面完整 | 三窗 + 主屏三区 + 能力表面 + handoff；vitest + CI（仅 macOS） |
| mobile 伴生端 | 局域网闭环 | 对话/审批/动态/记忆，配对+HTTPS+PWA 齐全；**无外网** |
| extension | 小而完整 | MV3 素材桥，手动加载，**未上架** |

### 主要短板（review 结论）

1. **分发是最大短板**：只出 `.app`（DMG 因中文 productName 卡住）、未签名未公证、`macOSPrivateApi` 永别 App Store、Windows 只有踩坑笔记零实现、CI 单平台。
2. **单 run 限制**：一次只处理一个对话，并发需改 server（`desktop/README.md` 已知限制）。
3. **体验债**：Live2D 形象未做（现为 SVG 团子）、深色模式只留骨架、TTS 边收边播在 backlog、watch 在场陪伴是占位行为。
4. **架构债**：`server.py` 1933 行拆分未完（background.py 是半成品搬迁）；coding 插件仍 in-process。
5. **测试缺口**：notes/forge 无专属测试；schema 面板类插件无 UI 层测试（coding 除外）。
6. **当前工作区有 R4 收尾的未提交改动**（plugins/coding/panel 9 个文件），需先落账。

## 二、Roadmap 草案

### 阶段 A：收口 + 可分发（建议优先，1–2 周）

> 理由：功能已远超「可分发的 v1」，但分发链路是零。这是把已有价值兑现的最短路径。

- A0. 落账 R4 收尾改动（coding panel 9 个 dirty 文件，跑闸后提交）
- A1. DMG 打包：解决中文 productName 与 create-dmg 冲突（英文 productName + 中文显示名，或换 dmg 方案）
- A2. 开发者证书签名 + 公证（站外分发，去掉 `xattr` 门槛）
- A3. 版本号与更新策略：定 v1.2 基线，评估 Tauri updater
- A4. CI 补 panel/前端闸已在仓内，加 release workflow（tag → build → 产物）

### 阶段 B：核心体验深化（2–4 周，按选题）

- B1. **P2 督导模式**（`docs/research/2026-08-16-yibao-collab-patterns.md` 三步走的最后一步）：后台任务 steer + 多 agent 并行督导；studio 左栏已具雏形，是自然延伸
- B2. **并发对话**：解除单 run 限制（server 改队列/并发模型），coding 多工位时代这限制越来越扎眼
- B3. **语音链路提速**：TTS 边收边播（~0.95s 起音）+ websocket 复用（`docs/reports/2026-08-01-v1.1-slice1-baseline.md` backlog）
- B4. **深色模式交付**：令牌骨架已留，补全即可
- B5. ~~watch 在场陪伴做实（当前占位不出声）~~ ✅（2026-08-24）：根因=perception.activity 开关缺省关闭致 Ambient 三信号零触发（feed 180 条零 ambient）；补 signal 字段（greeting/welcome/milestone）+ usePetEvents 反应分支（里程碑→success 星芒，问候→notify 招手）+ 开关打通端到端验证（feed 落账 + 双窗气泡）

### 阶段 C：形象与差异化（投入大，择机）

- C1. **Live2D 形象**（`docs/research/2026-07-16-landscape-research.md` 有完整选型基线：AIRI/Open-LLM-VTuber 蓝本）——产品灵魂级升级，但工作量最大
- C2. idle 生命感动效（os-feel-design 遗留，小投入点缀）
- C3. 点击 grounding 盲桶（Canvas/Electron/网页）精度提升

### 阶段 D：平台扩展（按目标用户决定）

- D1. **mobile 外网方案**（Tailscale/relay 二选一）——coding 竞品研究指出「远程/移动监控」是品类第一痛点，这是译宝的错位优势，值得优先
- D2. **Windows 支持**：从零做起（透明窗、热键、a11y、sidecar 原语全部要平台层），工作量大；先做技术验证再决定
- D3. extension 上架 Chrome Web Store + 团子图标替换占位图
- D4. coding 插件 out-of-process 化（manifest 已留口子）

### 阶段 E：工程健康（穿插进行，不单列阶段）

- E1. `server.py` 拆分收尾（background/permissions/invoker 接线剥离）
- E2. notes/forge 补测试；schema 面板通用渲染层补快照测试
- E3. LLM provider 抽象整理（GLMProvider 已更名 OpenAICompatProvider、留旧名别名，命名/注释已对齐；后续若要拆文件再单开）
