# 主屏余光：现有零件换脸 + 四块新 glance

日期：2026-08-21  
状态：落地中  
前篇：零件北极星（对话里的清单）；装配仍遵守 `home-place-engines-design.md`

## 一句话

空着就空着。有内容时，零件要能按、能看钟点、能呼吸；新零件只加译宝桌上才有的四块：想起、余光、接到、草稿纸。

## 空态

`need` `tasks` `remind` `spark` `glimpse` `catch` 没有内容时不渲染 `.yb-widget`。Frame 用 `:has` 把空宿主收掉。`today` 全零时只留一条未染色的边。`scratch` 可以一直空。插件 glance 没有正文就不上桌。

## 现有零件

| id | 脸 |
| --- | --- |
| `need` | 一张能按的纸：同意 / 驳回在瓷上完成 |
| `tasks` | 正在转的那一件 + 卡点（等你 / 在跑） |
| `remind` | 下一条带钟点，90 分钟内加紧；优先插件待办行，其次 Feed |
| `identity` | 有确认时招手（`notify`）；三栏 tile 也把团子做大、少字 |
| `mind` | 余光是器官：去掉「认知」标题；闲着暗、想着亮 |
| `today` | 一条染色纸边，不是三个 0 |

三栏把 `need` `tasks` `remind` 放进左栏（空则消失），不再 `absent`。

## 新零件

| id | 是什么 | 放哪 |
| --- | --- | --- |
| `spark` | 一句和此刻有关的旧记忆，可贴走 | 三栏左、整桌书边、会客跟身份、画布一窗 |
| `glimpse` | 刚看见的前台应用，起雾小窗 | 三栏左、整桌书边、画布；会客不要 |
| `catch` | 刚到手：剪贴板 / 闪念 | 三栏左、整桌右、画布；会客不要 |
| `scratch` | 可写的角，只存在本机 | 整桌右、画布；三栏/会客不要 |

换摊法不是换零件。Frame 不读预设名。不登记天气时钟。
