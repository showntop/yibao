# 工位留痕：足迹，不是开关账本

日期：2026-08-21  
状态：落地中  
前篇：`2026-08-21-plugin-host-presence-design.md`

## 一句话

主对话里的工位留痕是**足迹**：每到一个工作面落一只脚印。不是开一行、关一行的开关日志，也不是「今天用过哪些手」的摘要。

## 为什么改

当前实现把开写成左边虚线协作卡（`摊开 … 展开 ›`），关写成居中淡字（`收起 …`）。一对占两行，左右拉锯，同一次逛还会各记一遍。路径把说话和干活切开了。

用户要留痕，而且要像足迹，不要合成次数。

## 规则

1. **一次到访 = 一只脚印。** 摊开工位时追加一条。收起**不另起一行**，也不写 `收起` / `已走`。
2. **再来一次 = 新脚印。** 闪念盘来过两回，就两只「摊开 闪念盘」。不合成 `· 2 次`。
3. **误触不算第二只。** 收起后马上摊开**同一面**，且中间没有用户话、也没有一轮工作（过程行 / AI 正文），沿用上一只脚印，不追加。
4. **换了对象就算新路。** 闪念盘 → 工具箱 → 闪念盘，三只脚印。中间隔了对话再回闪念盘，也是新脚印。
5. **文案三档不变，视觉同一家族。** 译宝脑 `摊开 闪念盘`；无脑 `用了 工具箱`；工人脑 `已请 改登录`。名字仍走 `deskWho`（一个给人看的名字）。
6. **脚印不是协作卡。** 不用虚线框、不用「展开 ›」。一行居中淡字，字号跟 sys 提示一类。整行可点，再摊开那只手。
7. **旧的关行藏掉。** 历史上已写入的 `收起 …` / `已走 …` 不再画出来（含没有 `·` 的短句）。开行保留，改用脚印脸。

## 何时落脚印

工位从无到有，或从 A 换到 B 时，对**新面上的那只手**落一只。判定仍是 `deskKind`（工人脑 / 译宝脑 / 无脑）。

不落：

- 同一工位还摊着，面板数据刷新（`isResumeDeskWork`）
- 上面第 3 条的误触
- 后台派生、小窗、面板窗（本轮仍不做）

收起、切走、问译宝浮层：都不追加关行。内存里清掉「当前工位」，脚印留在原处。

## 样子

| 状态 | 画法 |
| --- | --- |
| 过去的脚印 | 居中、淡色、无框、无「展开 ›」 |
| 当前工位对应的那只 | 同一套字，略不那么淡（纸被工位盖住时用户本来看不见；收起后这条仍在时间轴上） |
| 点按 | 整行 = 再摊开；没有第二套按钮文案 |

不要把脚印画成 AI 气泡，也不要画成左边虚线 CTA。

## 账本（取代前篇第四拍的开/关两行）

| 档 | 对话里留下的 |
| --- | --- |
| 无脑工具 | `用了 工具箱` |
| 译宝脑 | `摊开 闪念盘` |
| 工人脑 | `已请 改登录` |

工位顶栏、Glance 压痕、译宝请来仪式：仍按前篇，本轮不改。

## 落地边界

改：`home-desk-presence`（误触判定；关行不再作为配对）、`HomeChat`（只在打开时 stamp）、`work-thread`（藏关行）、纸面/线索里脚印的渲染（`HomeChatPaper` / `HomeChatThread`）。

不改：sidecar 路由、小窗、Glance 文案、工人脑顶栏「译宝请来」。

不把多只脚印收成一条「今天走了：…」。
