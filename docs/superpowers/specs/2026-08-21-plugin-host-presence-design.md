# 插件在场：译宝不退场

日期：2026-08-21  
状态：原型落地中  
前篇：能力表面 `2026-08-09-capability-surfaces-design.md`；输入 handoff `2026-08-19-input-handoff-design.md`

## 一句话

译宝是操作系统。插件是它的手。切换之后用户仍在跟译宝合作；工作面只换对象，不换人。coding 可以换执行脑，那是委派，不是换搭档。

## 硬约束

1. **社会搭档只有译宝。** 嘴（打字、说话）对着译宝；手可以放在摊开的面上。
2. **插件不是目的地。** 不切「插件」页、不把用户送进插件房间。轻的在桌上（回执/探窗/glance）；重的把书桌中间的纸换成工位。
3. **换脑要被看见，换人禁止。** coding 的 Composer 可以听 Claude Code / Codex，但叙事是「译宝请来」，不是「插件接管」。
4. **主人在场。** 团子留在桌上（身份砖）。想跟译宝本人说，点团子，不必先回主屏。handoff 时桌沿译宝条让位，团子不流亡到标题栏。

## 三种换脑

| 档 | 何时 | 输入 | 认知 |
| --- | --- | --- | --- |
| 首次请上工位 | 明确打开 / 继续改 | 槽上出现 `译宝请来 · 插件` | 委派一次 |
| 接着干 | glance / 活动胶囊 / 恢复 | 不再发委派 | 恢复现场 |
| 后台派生 | 「弄完告诉我」 | 嘴不借出 | 译宝继续听 |

## 本轮原型（能看见的那一版）

大窗主屏打开 stage/focus 时：

- 桌子不拆（glance、身份、会话脊还在）
- 中间那张纸换成工位；顶条文案是「译宝请来」+ 工人名 + 收起
- 插件页头 / 插件工作台条在场景里藏掉，避免第二套助手
- `input=handoff` 时桌沿输入条让位（工人自带 Composer）；身份团子仍在
- 插件目录 tab 行为不动（仍是目录，不是工位）

## 第二拍（接着干）

- 首次请上工位：复用关联卡，文案是 `已请 coding · 改登录`（不再写「正在和 xxx 协作」）；同一面板恢复原地更新
- 收起工位：线程落一条 `已走 coding · 改登录`；切到另一只手时先走再请。`协作结束` 并进这一句
- handoff 时点身份团子或工位上「问译宝」，浮层直问译宝，工位不收
- 从 glance / 本次相关插件行点开：记下瓷片矩形，工位从那里长出、缩回那里

## 第三拍（委派仍在桌上）

工位顶栏已经是委派署名（`译宝请来 · coding`），不要再叠一条 `已请`。

- 译宝脑 / 无脑 / 工人脑在对话里都留足迹（一次到访一行）；收起不另写。详见 footprints spec。
- 桌上的活信号是 glance 压成「正在用」；再点这块瓷，工位缩回去
- 按插件名前缀认同一只手（`coding:widget` 对上 `coding:studio`）

## 第四拍（三档谁在想）

已请 / 「译宝请来」只给工人脑。译宝脑和无脑写摊开/用了。三档都只落脚印，不写关行。

| 档 | 判定 | 账本 | 工位顶栏 | Glance |
| --- | --- | --- | --- | --- |
| 无脑工具 | `toolbox` 或 `input=none` | 一只脚印：`用了 工具箱` | 工具名 + 收起 | 仍写摊开，不写正在用 |
| 译宝脑 | 缺省 | 一只脚印：`摊开 闪念盘` | 对象名 + 收起 | 正在用 |
| 工人脑 | `input=handoff` 或 coding | 一只脚印：`已请 改登录` | 译宝请来 + 问译宝 | 正在用 |

对话留痕改为足迹（一次到访一行，收起不另写）。详见 `2026-08-21-desk-path-footprints-design.md`。

仍不做：小窗/面板窗、改 sidecar 路由、后台派生单独视觉
