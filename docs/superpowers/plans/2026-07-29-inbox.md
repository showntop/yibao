# 任务收件箱核心（§4.5 子项目 A）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把散装的确认弹窗（4 处 popup + 单槽逐个阻塞）升级为收件箱：loop 一轮多 CONFIRM 攒批 + server 多槽 + batch confirm API + 大窗收件箱（多选一键批）+ 小窗/面板窗单条快批 + 4 处 popup 分级退役。

**Architecture:** confirmer 接口从「单 action → bool」改为「list[action] → dict[id, verdict]」批量；loop 一轮收集 CONFIRM、批量等、按 LLM 顺序执行；server `pending_confirm` 单 future → 多槽 dict + `confirm_batch` IPC；前端大窗收件箱批量批、小窗/面板窗单条快批、大窗 popup 退役。

**Tech Stack:** Python 3.12 / pytest、Rust / Tauri v2、Vue 3 / TypeScript。

## Global Constraints

- `confirmation_needed` 事件载荷从单个 `action` 改为 `actions: list`（兼容单条 = 长度 1）。
- `confirm_batch` IPC 统一替旧 `confirm` 单条 IPC（小窗单条快批也走 batch size=1）。
- 执行严格按 LLM 顺序（CONFIRM 批量等但不重排，依赖链 B 用 A 结果仍安全）。
- loop 并行执行、多 run 并发均为非目标（不做）。
- `PendingConfirm.tier` 预留但不实装 tier 逻辑（C 子项目）。
- sidecar `cd sidecar && uv run --extra dev pytest -q` 全绿；前端 `cd desktop && npx vue-tsc --noEmit && npm run build` exit 0；Rust `cargo check --manifest-path desktop/src-tauri/Cargo.toml`。

**Spec:** `docs/superpowers/specs/2026-07-29-inbox-design.md`。

- [ ] **Step 3: 实现（spec §3.2）**

```python
pending_confirms: dict[str, asyncio.Future] = {}
early_answers: dict[str, tuple[bool, bool]] = {}

async def batch_confirmer(actions) -> dict[str, tuple[bool, bool]]:
    results = {}
    for a in actions:
        if a.id in early_answers:
            results[a.id] = early_answers.pop(a.id)
        else:
            fut = pending_confirms.setdefault(a.id, asyncio.Future())
            results[a.id] = await fut
    return results
```
serve_async 分发（替旧 `confirm`）：
```python
elif rtype == "confirm_batch":
    for item in (msg.get("items") or []):
        cid, approved, remember = item["id"], bool(item["approved"]), bool(item.get("remember"))
        if cid in pending_confirms and not pending_confirms[cid].done():
            pending_confirms[cid].set_result((approved, remember))
        else:
            early_answers[cid] = (approved, remember)
    write_msg({"type": "confirm_batched", "ok": True})
```
