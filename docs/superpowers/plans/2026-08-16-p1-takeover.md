## 任务表

### T1 桥事件通道（WebviewPanel.vue，独立文件）
- BRIDGE_JS 加 `onMessage(cb)`（host 消息中非 init/非 invoke 响应的分发）与 `emitEvent(name,payload)`（发 `{src:"yibao-webview",event,payload}` 无 id）；init 回调改 `(data, fullMsg)`
- onMessage：id 检查前先分流 `d.event` → `emit("panel-event", d.event, d.payload)`；加 defineEmits
- 新 prop `takeover?: boolean`；postInit 载荷加 takeover 字段
- defineExpose `postToIframe(msg)`（去 Proxy + 补 src 后 contentWindow.postMessage）
- reviewer 审：消息协议后向兼容（旧 iframe 无 emitEvent 不崩）、init 时序（@load 首次 postInit 即带 takeover）

### T2 InputBar takeover 化（InputBar.vue，独立文件，与 T1 并行）
- props 加 `placeholder?: string`（默认「对译宝说点什么…」保持现文案）、`takeover?: boolean`
- `stopping = busy && !listening && !takeover`；takeover 时 send() 不 emit interrupt
- IME 守卫：compositionstart/end 监听 + lastCompEnd 50ms；Enter 改 `@keydown.enter.exact.prevent="onEnter"`，onEnter 判 isComposing/时间窗再 send
- defineExpose 加 `insertText(t)`：追加文本 + persistDraft + nextTick autoGrow + focus
- reviewer 审：非 takeover 行为零回归（stopping/interrupt/草稿/自增高）

### T3 chat.html 接管模式（依赖 T1 桥接口；单文件）
- `window.yibao.onInit((data, msg)=>…)` 里取 `msg.takeover` → `setTakeover(bool)` → `body.takeover` class
- CSS：`body.takeover .prompt-wrap{display:none}` `#send{display:none}`；keys 行 ↵发送/⇧↵换行 两个 hint span 加 class 在 takeover 隐藏（esc 停止/@ 文件保留）
- `yibao.onMessage`：`takeover-input`（busy 则 push 到 `takeoverQueue` + setStatus「已排队，本轮结束后自动发送」；否则 `$("prompt").value=text; send()`）；`takeover-stop`（streaming||sending 时 stop()）
- onSessionEnded 末尾：takeoverQueue 非空 → shift → 填值 send()
- `reportState(st)` 助手 + 迁移点埋点：sending=true→sending；streaming=true→streaming；permission_request→waiting；permission_done→streaming；onSessionEnded→idle（若即将自动发队列则由下次 send 重新报 sending）；newChat→idle；catch→idle
- reviewer 审：非 takeover 路径零变化；队列竞态（stop 后队列应清空——stopped 不自动发）；layoutRunPill 在 footer 变矮后仍正确

### T4 PanelApp 接线（依赖 T1/T2/T3 接口）
- `isCoding = computed(() => current?.panel === "coding:chat" && !!webviewHtml)`；ref webviewRef/inputBarRef
- 模板：WebviewPanel 加 `:takeover="isCoding"` `@panel-event="onPanelEvent"`；InputBar 加 `:placeholder`（isCoding 时「编码智能体接管中，直接说任务…」）`:takeover="isCoding"`
- submit(text)：isCoding → `webviewRef.postToIframe({type:"takeover-input",text})`（不 pushMsg 不 runInput）；否则原逻辑
- onPanelEvent：`takeover-state` → avatar state 映射（idle↔idle，其余→work）+ reportPanelContext（item.title 带状态文案：提交中/运行中/等待审批/空闲）；`insert-draft` → `inputBarRef.insertText(payload.text)`
- setCurrent 进入 coding → pushMsg("hint","编码智能体已接管输入条，直接对它说任务；点左上角关闭或切走即交还")（仅一次）
- esc 转发：document keydown，isCoding && state!=="idle" && e.key==="Escape" → postToIframe({type:"takeover-stop"})（不抢浮层收起等既有 esc 语义——先查现有 esc 监听无冲突）
- onInterrupt：isCoding 时改发 takeover-stop 而非 brain interrupt
- reviewer 审：非 coding 面板零回归；切面板/关窗时 takeover 状态清理；AvatarState 不被打架（brain 事件同刻迁移）
