# 移动端 M2（信息浏览 + 底部导航）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 手机端补齐信息浏览：Feed 动态流、待办提醒管理、记忆库查看；导航升级为底部 Tab（对话/动态/审批/设置）。三席：T1 server 端点、T2 导航+Feed+提醒、T3 记忆库+M1 遗留顺手项。

**Architecture:** server 把三块现成 stdio IPC 移植到 /v1（feed 复用 serve_async 既有 `_feed` 组装；reminders 走直连插件 API `reminders.list/cancel`（`_bridge_save` 的 propose/decide/execute 直调模式，锚点 `server.py` 的 `_bridge_save`）；memories 复用 `_mem_list`）。mobile 落 TabBar 组件 + Feed/记忆页。

**Spec:** `docs/superpowers/specs/2026-08-14-mobile-companion-design.md` §15 M2（导航结构同节）

## Global Constraints

- `server.py` 跨会话 WIP hunk 过滤红线（同 M1，关键词按任务：feed/reminders/memories）
- 不引新依赖；mobile 测试 vitest fake 注入；先红后绿；中文注释
- Feed/提醒/记忆均为**只读为主**（提醒可取消）；不做桌面编辑功能的手机复刻（YAGNI）

### Task 1:（server）/v1/feed + /v1/reminders + /v1/memories

**Files:**
- Modify: `sidecar/src/yibao_brain/http_api.py`（三路由，未接线 503 模式照 v1_state）
- Modify: `sidecar/src/yibao_brain/server.py`（deps 闭包三枚 + 接线；feed 组装复用 :1403 feed 分支的逻辑提取）
- Test: `sidecar/tests/test_http_api.py`（fake 路由级）+ `sidecar/tests/test_server.py`（feed 闭包真形状，注入 FakeProvider 跑一轮后 feed 有记录——若成本高退为直调闭包断言形状，M1-T1 已有先例）

**Interfaces:**
- Produces:
  - `GET /v1/feed?limit=60` → `{ok, items, stats, running_tasks}`（与桌面 feed IPC 完全同形；items 倒序）
  - `GET /v1/reminders` → `{ok, items:[...]}`（reminders.list 直连返回 data；空/异常→空列表不 500）
  - `POST /v1/reminders/cancel` `{id}` → `{ok}`（reminders.cancel 直连；失败 500 带 error）
  - `GET /v1/memories` → `{ok, items}`（_mem_list 现成）
  - `MobileDeps.feed / reminders_list / reminders_cancel / memories` 四闭包

- [ ] Step 1: 测试先红（fake deps 形状 + 未接线 503 + cancel 失败 500）
- [ ] Step 2: 实现四闭包：feed 闭包搬 dispatch feed 分支主体（`feed.recent/_feed_stats/_running_tasks` 闭包内可用——若它们定义位置晚于 deps 组装点则把组装点下移或惰性调用）；reminders 用 `_bridge_save` 同款直调（`get_api("reminders.list")` + propose/decide==AUTO + `_offload(execute)`）；memories 直接 `await _mem_list()`
- [ ] Step 3: 全量绿 → hunk 过滤提交 `feat(server): /v1/feed+/v1/reminders+/v1/memories——移动端信息浏览端点`

**Files:**
- Create: `mobile/src/components/TabBar.vue`、`mobile/src/state/feed.ts` + `feed.test.ts`、`mobile/src/state/reminders.ts` + `reminders.test.ts`、`mobile/src/views/Feed.vue`

**Interfaces:**
- Produces:
  - `useFeed(conn, fetchImpl=fetch)` → `{ items: Ref<FeedItem[]>, stats, running, refresh() }`（FeedItem 形状以服务端 /v1/feed 为准，渲染层只取 kind/text/created_at 类字段——执行时先 curl 一发真实形状再定 interface，报告记录）
