### Task 2:（docs）分享送素材配置模板

**Files:**
- Create: `mobile/docs/share-setup.md`
- Modify: `mobile/README.md`（链接一节）
- Modify: `mobile/src/views/Settings.vue`（「分享到译宝」一节：一句话说明+链接指向上文路径提示——纯静态文案）

**内容契约（share-setup.md 必须含）：**
1. **iOS 快捷指令**（逐步）：快捷指令 App → 新建 → 添加「在分享表单中显示」（接收文本/URL）→ 动作「获取 URL 的内容」POST `http://<Mac内网IP>:19527/v1/save`，头 `X-Yibao-Token: <mtok>`，JSON body `{"text":<快捷指令输入的文本>,"title":"","url":"","mode":"material"}`；注明 token 从桌面设置页取、IP 换网会变。
2. **Android HTTP Shortcuts**（应用市装 → 新建 Shortcut → Method POST 同 URL/头/体 → 开启「Share 接收」）。
3. **验证**：手机任意 App 分享一段文字 → 桌面素材库出现。
4. 局限注明：LAN 内可用（外网等联网方案）；敏感 token 存于快捷指令的风险提示。

- [ ] Step 1: 写文档 + README 链接 + Settings 文案；`pnpm build` 仍绿 → 提交 `docs(mobile): 分享送素材配置模板——iOS 快捷指令/Android HTTP Shortcuts`
